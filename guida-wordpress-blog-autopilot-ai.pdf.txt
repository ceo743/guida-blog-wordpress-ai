STEP 1
Preparare WordPress
WordPress ha un'API REST integrata che permette a strumenti esterni di creare e pubblicare post. Per
usarla in modo sicuro, genererai un'Application Password: una credenziale speciale che dà accesso
all'API senza esporre la tua password principale.
Come creare un'Application Password:
1. Accedi alla dashboard WordPress (tuosito.com/wp-admin)
2. Vai su Utenti → Profilo
3. Scorri fino alla sezione Application Passwords
4. Inserisci un nome (es. "Blog Automation")
5. Clicca Add New Application Password
6. Copia la password generata — non la vedrai più
IMPORTANTE Conserva questa password in un posto sicuro. Ti serviranno sia il tuo username
WordPress che questa application password per configurare l'automazione.
Testa l'accesso API:
Apri un terminale ed esegui questo comando per verificare che l'API funzioni:
curl -s -u "tuo-username:xxxx xxxx xxxx xxxx" \
  "https://tuosito.com/wp-json/wp/v2/posts?per_page=1"
Se ricevi una risposta JSON con il tuo ultimo post, l'API funziona correttamente.

STEP 2
Content Strategy
Prima di automatizzare, ti serve un piano editoriale. L'approccio migliore è creare una lista di
argomenti a rotazione: una sequenza numerata che l'automazione percorre settimana dopo
settimana.
Come costruire la lista:
 Punta a 20-30 argomenti — coprono 5-7 mesi prima di ripetersi
 Organizza per categoria (prezzi, guide, consigli locali, FAQ)
 Scrivi il titolo esatto per ogni argomento in anticipo
 Includi una focus keyword per ogni post (la query di ricerca target)
 Aggiungi una breve descrizione di cosa deve coprire il post

STEP 3
Definire la Style Guide
L'automazione ha bisogno di istruzioni chiare per la scrittura, così ogni post risulta coerente con la tua
brand voice. Ecco un template che puoi personalizzare:
Tono
Educativo, utile, stile how-to step-by-step. Amichevole ma autorevole.
Lunghezza
Minimo 1.000-1.500 parole per post.
Struttura
 Cattura il lettore nelle prime 2-3 frasi con uno scenario reale
 Usa heading H2 e H3 chiari per organizzare il corpo
 Chiudi con una conclusione che si ricollega all'intro
 Includi una call-to-action morbida che menziona il tuo business
Regole SEO
 Includi la keyword target nelle prime 100 parole
 Usa la keyword in almeno un sottotitolo
 Menzionala 2-3 volte in modo naturale nel testo
 Non fare keyword stuffing
Riferimenti locali
Menziona la tua città, regione e condizioni locali dove rilevante.
Valore pratico
Includi numeri specifici, prezzi, tempistiche o istruzioni step-by-step dove possibile.

STEP 4
Task Automatico
Qui avviene la magia. In Claude Cowork mode (o Claude Code) creerai un task schedulato che viene
eseguito automaticamente ogni settimana.
Cosa comunicare a Claude:
1. Le tue credenziali WordPress — URL del sito, username e application password
2. La tua lista completa di argomenti — tutti numerati con titoli, keyword e descrizioni
3. La tua style guide — tono, lunghezza, struttura, regole SEO (dallo Step 3)
4. La schedulazione — es. "Ogni lunedì alle 9:00"
5. Istruzioni di pubblicazione — digli di usare l'API REST di WordPress per pubblicare
Esempio di prompt (personalizza le sezioni tra parentesi):
PROMPT // CREA IL TASK SCHEDULATO
Create a scheduled task that automatically writes and publishes
one new blog post each week to my WordPress site.
Site: [tuosito.com/wp-admin]
Username: [tuo-username]
Application Password: [xxxx xxxx xxxx xxxx xxxx xxxx]
Schedule: Every Monday morning at 9 AM
Topics (rotate through these in order, never repeating):
1. [Titolo Topic 1] - Focus: [keyword]. Cover [descrizione].
2. [Titolo Topic 2] - Focus: [keyword]. Cover [descrizione].
3. [Titolo Topic 3] - Focus: [keyword]. Cover [descrizione].
[...continua per tutti i topic...]
Writing style:
- Tone: Educational, how-to style
- Length: 1,000+ words
- Include local references to [tua citta/regione]
- End each post with a CTA for [nome tuo business]
- Follow SEO best practices for the focus keyword
Come l'automazione sceglie il topic:
Il task è progettato per controllare i tuoi post più recenti tramite l'API WordPress, confrontarli con la
lista di argomenti e pubblicare il prossimo topic in sequenza. Dopo l'ultimo argomento, riparte
dall'inizio.

DOMANDE FREQUENTI
Posso cambiare la schedulazione dopo averla configurata?
Sì. Puoi aggiornare il task schedulato in qualsiasi momento per cambiare giorno, orario o frequenza.
Cosa succede quando tutti gli argomenti sono stati pubblicati?
L'automazione riparte dal Topic 1. A quel punto sono passati mesi — puoi aggiornare gli argomenti o
lasciarli ciclare con contenuto aggiornato.
Posso modificare i post dopo la pubblicazione?
Assolutamente. L'automazione pubblica una prima bozza solida. Puoi sempre accedere a WordPress
e perfezionarla.
Funziona con WordPress.com?
Questa guida è scritta per WordPress self-hosted (WordPress.org). WordPress.com ha un'API
diversa, ma un approccio simile può essere adattato.
L'Application Password è sicura?
Le Application Password sono credenziali a scope limitato — non espongono la tua password
principale. Puoi revocarle in qualsiasi momento dal tuo profilo WordPress.
E se il post generato non mi piace?
Aggiorna il prompt del task con istruzioni più specifiche. Puoi indicare esattamente lo stile, il tono, la
struttura e i riferimenti da includere. Più dettagli dai, migliore è il risultato.
Quanto costa mantenere l'automazione?
Il costo principale è l'abbonamento a Claude. Non ci sono costi aggiuntivi per l'API WordPress
(inclusa nel self-hosted). Il ROI è immediato: risparmi 3-5 ore a settimana di scrittura.
